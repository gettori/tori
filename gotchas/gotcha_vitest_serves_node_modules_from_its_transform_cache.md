# vitest serves node_modules from its transform cache

Do NOT expect a `console.log` patched into a dependency under `node_modules` to show up: vitest replays the transformed dep from its cache, so the run looks identical. Why: the stack trace names the file (`dist/index.jsx`), but the code that runs came from `node_modules/.vite`. Pass `--no-cache` for the diagnosis run, and patch `dist/index.js`, the entry the resolver actually picks.
