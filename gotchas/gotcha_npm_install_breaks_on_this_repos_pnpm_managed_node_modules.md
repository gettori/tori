# `npm install` breaks on this repo's pnpm-managed `node_modules`

This repo uses `pnpm` (see `pnpm-lock.yaml`, no `package-lock.json`); running `npm install <pkg>` fails outright with an internal npm error (`Cannot read properties of null (reading 'edgesOut')`) because npm can't reconcile pnpm's symlink-based `node_modules` layout into its own "ideal tree". Always use `pnpm add <pkg>` in this repo.
